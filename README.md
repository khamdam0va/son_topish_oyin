# Son topish o'yini 🎯

Python'da yozilgan oddiy konsol o'yini. Kompyuter 1 dan 100 gacha son o'ylaydi, siz uni 7 ta urinishda topishingiz kerak.

## Qanday o'ynaladi
- Dastur sonni o'ylaydi
- Siz taxmin kiritasiz
- Dastur "kattaroq" yoki "kichikroq" deb yo'l-yo'riq beradi
- 7 ta urinishda topsangiz, yutasiz

## Ishga tushirish
Kompyuteringizda Python o'rnatilgan bo'lishi kerak.

    python main.py

## Kelajakda qo'shiladigan narsalar
- [ ] Qiyinlik darajalari
- [ ] Eng yaxshi natijani saqlash
- [ ] Kompyuter sonni topadigan rejim
